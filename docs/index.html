ytlrc

Synced YouTube lyrics in your terminal. Tiny Rust daemon + Chrome/Edge extension. No API keys, no account, no audio fingerprinting, ~1.4 MB binary.

Why ytlrc?

No API keys

LRCLIB is public. Nothing is uploaded except playback metadata, and only to 127.0.0.1 on your own machine.

Lives in your terminal

SSH, tmux, a tiling WM — anywhere a normal ratatui app runs.

Tiny footprint

~1.4 MB static binary, ~10–15 MB RAM. No runtime besides curl.

Self-healing

Automatic song-change detection, retries with backoff, and a stale-lyrics watchdog.

Per-word karaoke

When LRCLIB has enhanced LRC timing, the active line highlights word by word as it's sung.

Accessible

NO_COLOR=1 and REDUCE_MOTION=1 are respected; keybindings are remappable.

Get it running

# Linux / WSL (static binary)
./build.sh && ./ytlrc --bind 0.0.0.0

# macOS
./build.sh && ./ytlrc

# Windows (PowerShell)
.\build.ps1; .\ytlrc.exe

Then load the extension/ folder as an unpacked Chrome/Edge extension and play something on YouTube. Full instructions are in the README.
